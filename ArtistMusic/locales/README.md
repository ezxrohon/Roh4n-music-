# Multi-Language Telegram Music Bot

A feature-rich music bot with localization support and voice chat playback.

## Features

- High-quality audio playback
- Smart queue management
- Multi-assistant support
- Group voice chat integration
- Multi-language localization support

## Supported Languages

This bot ships with localized translations in the `locales/` directory.

- English
- Hindi
- Urdu
- Spanish
- Telugu
- Arabic
- Russian
- French
- German
- Portuguese
- Bengali
- Turkish
- Indonesian
- Japanese
- Korean
- Chinese
- Vietnamese
- Thai
- Persian
- Burmese
- Nepali
- Bhojpuri
